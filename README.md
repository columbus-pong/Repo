## My Favourite Math Formulas

A collection of useful mathematical formulas formatted in LaTeX for clear rendering on GitHub.



### 1. Parabolic (Quadratic) Function
$$y = \alpha x^2 + \beta x + \gamma$$

* **Description:** The general form of a quadratic function, which visually represents a parabola.
* **Components:** $\alpha, \beta, \gamma$ denote the coefficients, and $x$ represents the input variable.

### 2. Modified Hyperbolic Function
$$y = \frac{k_1}{k_2 x + c}$$

* **Description:** A fractional-linear function whose graph forms a hyperbola.
* **Components:** $k_1, k_2$ denote coefficients, $x$ is the input variable, and $c$ is a constant value.

### 3. Solving Quadratic Equations
To find the solutions for an equation in the form of $ax^2 + bx + c = 0$, we first calculate the discriminant ($D$):
$$D = b^2 - 4ac$$

Then, we find the roots ($x_1, x_2$) using the quadratic formula:
$$x_1 = \frac{-b + \sqrt{D}}{2a}, \quad x_2 = \frac{-b - \sqrt{D}}{2a}$$



### 4. System of Linear Equations
An example of a system of three linear equations with three unknown variables ($x, y, z$):

$$
\begin{cases} 
2x + 3y - z = 7 \\ 
4x - y + 2z = 4 \\ 
-x + 2y + 5z = 11 
\end{cases}
$$

* **Description:** A set of equations that share the same variables, where the goal is to find values for $x, y$, and $z$ that satisfy all equations simultaneously.

### 5. Sum of the First $N$ Positive Integers
The formula to quickly calculate the total sum of consecutive integers from $1$ to $n$:

$$\sum_{i=1}^{n} i = \frac{n(n + 1)}{2}$$

* **Description:** Also known as the formula for the sum of an arithmetic progression, representing the total of $1 + 2 + 3 + \dots + n$.

### 6. Identity Matrix of Rank $N$
A square matrix denoted as $I_n$, which serves as the multiplicative identity in matrix algebra:

$$
I_n = \begin{bmatrix} 
1 & 0 & \cdots & 0 \\ 
0 & 1 & \cdots & 0 \\ 
\vdots & \vdots & \ddots & \vdots \\ 
0 & 0 & \cdots & 1 
\end{bmatrix}
$$

* **Description:** A square matrix of size $n \times n$ where all elements on the principal (main) diagonal are equal to $1$, and all other elements are equal to $0$. Multiplying any matrix by the identity matrix leaves it unchanged.
